# Bobcat Workhub

두산밥캣 직원을 위한 교육용 게시판·업무 대시보드 프로토타입입니다. GitHub Pages의 정적 HTML/CSS/JavaScript에서 Supabase Auth와 PostgreSQL REST API를 사용합니다.

## 기능

- 첫 접속부터 DB에 저장한 샘플 게시글 10개, 댓글 2개, 14일×2사업장의 가상 업무 지표 표시
- 이름·부서·이메일·비밀번호 회원가입, 이메일 인증, 로그인, 로그아웃
- 게시판 5개 분류, 검색, 페이지 이동, 글 상세, 글 작성·본인 글 수정·삭제, 댓글 등록·본인 댓글 삭제
- 생산 실적·계획 달성률·생산량 가중 양품률·안전 점검 이행률, 기간·사업장 필터
- 앞서 만든 Three.js 로더 시뮬레이션 연결

## 실행

`python -m http.server 8000 --directory dist` 후 http://localhost:8000 을 엽니다.

## DB

`schema.sql`은 초기 구축에 사용한 SQL입니다. 이미 적용된 프로젝트에 다시 실행하지 않습니다. `security-tests.sql`에 초기 권한 검증을 기록했고, 그 뒤 `login-policy.sql`을 적용해 샘플을 포함한 모든 조회를 로그인 사용자에게만 허용했습니다. 신규 구축 순서는 schema.sql → security-tests.sql → login-policy.sql입니다.

`dist/config.js`의 publishable 키는 브라우저 공개용입니다. 관리자 키·DB 비밀번호는 소스에 포함하지 않습니다. 비로그인 방문자는 게시글·댓글·지표를 조회하거나 작성할 수 없습니다. 로그인 화면만 표시합니다. 로그인 사용자의 글은 로그인한 사용자끼리 열람하고, 수정·삭제는 작성자에게만 허용합니다. 프로필의 이메일은 게시판 API에 공개하지 않습니다.

## 회원가입

실습용으로 이메일 확인을 해제했습니다. 이름·부서·이메일·비밀번호를 입력하면 인증메일 없이 바로 가입·로그인합니다. SMTP는 사용하지 않습니다. 회원과 로그인 세션은 Supabase Auth가 관리하고 글·댓글·지표는 PostgreSQL에 저장됩니다.

## 범위

모든 초기 게시글과 지표는 가상 교육 자료입니다. 공식 사내 포털이 아닙니다. 공개 회원가입이 가능한 수업용 앱이므로 회사 기밀·직원 개인정보를 입력하지 않습니다. 실제 사내 운영에는 직원 자격 검증·관리자 승인·계정 정책을 추가해야 합니다.

## 배포

`.github/workflows/pages.yml`이 `dist`를 GitHub Pages로 배포합니다. Auth의 Site URL은 배포 주소로 지정합니다.
